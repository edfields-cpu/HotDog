# Bratty Buns Hot Dog Stand

## Description

This Java program generates a menu containing all 128 possible hot dog combinations using seven different toppings. Each hot dog starts at $0.99, and the program calculates the total price based on the selected toppings.

## Requirements

- Java Development Kit (JDK)
- A terminal or command prompt
- Git

## Usage

1. Clone or download this repository.
2. Open the project folder in a terminal.
3. Compile the program using:

   `javac HotDog.java`

4. Run the program using:

   `java -ea HotDog`

The program will print all 128 possible combinations and their prices.

## Features

- Seven topping options
- Arrays for storing toppings and prices
- Automatic price calculations
- 128 possible hot dog combinations
- Formatted menu output
